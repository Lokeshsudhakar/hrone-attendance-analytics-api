# REVIEW.md

Review of the starter `app/main.py` (as handed over). I read every helper and
endpoint, compared each one with `openapi.yaml` (rules R1-R10) and
`DATA_MODEL.md`, and fixed each confirmed defect in place. Line numbers refer to
the starter file.

## Examined and *not* treated as defects

* **Sync PyMongo with sync `def` endpoints.** FastAPI runs them in a threadpool, so the event loop is never blocked; switching to Motor would rewrite every call site for little gain at this scale. (Trade-off noted in DECISIONS.md.)
* **`load_dotenv()` without `override=True`.** Real environment variables win over a local `.env`, exactly as the contract requires.
* **Default `MONGO_URI`/`MONGO_DB`.** Sensible local defaults; the grader injects its own values, nothing is hard-coded with real credentials.
* **Collection and field names in the starter.** `employees` / `attendance_logs` and the record fields already matched `DATA_MODEL.md`; only the response shapes and computations were wrong.
* **Single-file layout.** The contract requires all code in `app/main.py`; I kept one file with section banners instead of a package.
